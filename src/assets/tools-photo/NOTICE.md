# Tool photos

These 34 tool photos were generated by the project owner with an AI image
tool and supplied as collages (5 of them so far), then cropped into
individual files here (see git history for the crop coordinates).

This is the asset source the game actually uses (`ToolIcon.tsx`), chosen
over the free Microsoft Fluent Emoji 3D set in `../tools/` after a
side-by-side comparison: closer to real product photography, and each
photo's handle recolors cleanly with a CSS `hue-rotate` filter (desaturated
metal parts barely shift, the saturated handle clearly does), so the same
photos can still produce many distinct tile types via color variants.

The first 15 (hand tools) came from one collage. The next 12 (mostly power
tools, the gap the hand-tool set had) came from 3 more collages the user
sent that had heavy overlap with each other and with the first set; only
the genuinely new, cleanly-croppable ones were kept — a lot of repeated
pliers/wrenches/vises across those collages were skipped rather than
force-deduplicated.

A 5th collage (mostly a repeat of the earlier power-tool one) added 7 more
new tools (thermometer, stud finder, C-clamps, staple gun, both vacuum
types, soldering station); everything else in it duplicated what's already
in this list and was skipped.

Not used: a blowtorch and a laser-level image were duplicated across
collages, several pliers/snips/pipe-wrench/vise photos repeated the same
tool already covered above, and one thin tool (pen-shaped, unclear
identity) was dropped for being ambiguous at tile size.
