# Third-party assets

The PNG icons in this folder are 3D renders from Microsoft's **Fluent Emoji**
project (https://github.com/microsoft/fluentui-emoji), used under the MIT
license (Copyright (c) Microsoft Corporation).

Candidate set fetched for the tile-matching game's tool icons (pending
integration into `ToolIcon.tsx`):

| file | source emoji |
|---|---|
| martillo.png | Hammer |
| llave.png | Wrench |
| tornillo.png | Nut and bolt |
| destornillador.png | Screwdriver |
| sierra.png | Carpentry saw |
| brocha.png | Paintbrush |
| cajaHerramientas.png | Toolbox |
| mordaza.png | Clamp |
| escuadra.png | Triangular ruler |
| hacha.png | Axe |
| engranaje.png | Gear |

No free Fluent Emoji equivalent exists for the power tools (electric drill,
angle grinder, glue gun) or for a spirit level / Allen key — those either
stay as the earlier vector icons or need a different asset source.
